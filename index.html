Projects

Static site on S3 + CloudFront

We hosted this portfolio in an S3 bucket and served it over HTTPS through CloudFront.

AWS S3, CloudFront, bucket policy

Docker + CI pipeline

We packaged the site in an Nginx container. GitHub Actions builds the image and pushes it to Docker Hub on every commit.

Docker, Nginx, GitHub Actions, Docker Hub

Automated deployment on EC2

Our pipeline connects to an EC2 server over SSH and runs the new container. Nginx works as a reverse proxy on port 80.

AWS EC2, SSH, Nginx reverse proxy

Pipeline and server monitoring

Every push triggers a GitHub Actions build, with the status shown on this site. Our EC2 server is monitored with AWS CloudWatch (CPU, network and status checks). Grafana and Prometheus are planned as a future improvement.

GitHub Actions, AWS CloudWatch, Docker
