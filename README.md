# Team Portfolio Website

A portfolio website built during our Cloud Computing & DevOps internship at Maincrafts Technology.

Live site: http://13.236.207.176

## How it works
1. We push code to GitHub.
2. GitHub Actions builds a Docker image and pushes it to Docker Hub.
3. The deploy job connects to an AWS EC2 server over SSH and runs the new container.

## Tech used
AWS EC2, Docker, Nginx, GitHub Actions, Docker Hub
